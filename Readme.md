# Cartography and GIS Portfolio

## Author
**Alison Case**

## Description
This portfolio showcases my work in cartography and geographic information systems (GIS), highlighting my skills in app development, data visualization, and geospatial analysis. The website was developed as part of my coursework at the University of Wisconsin-Madison and serves as a personal showcase of my projects.

## Features
- **Interactive Web Maps**: Explore dynamic maps built with technologies like Leaflet, D3.js, and Mapbox Studio.
- **Portfolio Projects**: Includes a variety of projects, such as:
  - Country Roadmaps Interactive Map
  - Everglades National Park Wading Bird Sightings App
  - Public Health Outcomes and Risks App
  - Europe's Aging Cities
  - Public Art Guided Walking Tour
  - Ukrainian Refugees in Europe
  - Geographic Name Proposal App
  - Ukiyo-e Styled Basemap Tileset
  - StoryMap on the Rising Dengue Epidemic
  - Vacant Homes in Japan
  - Deaths on Lake Michigan
  - Reference Map of Africa
- **Responsive Design**: Built with Bootstrap for a seamless experience across devices.
- **Technical Skills**: Demonstrates proficiency in Python, JavaScript, HTML/CSS, React, PostgreSQL, and more.

## Technologies Used
- **Frontend**: HTML, CSS, Bootstrap, JavaScript
- **Libraries**: Leaflet, D3.js, React
- **Backend and Databases**: Supabase, PostgreSQL, PostGIS
- **Design Tools**: Adobe Illustrator, Mapbox Studio
- **Version Control**: GitHub

## About the Author
I am a cartographer and visual storyteller with a passion for leveraging GIS and modern web technologies to create engaging and informative visualizations. My professional experience includes roles in international development, strategic alignment, and program management.
